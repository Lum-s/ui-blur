# UiBlurPackage Changelog

## 0.1.1

- Renamed the Rojo project file to `default.project.json` so Wally installations
  resolve directly to the `src` module tree instead of exposing repository files
  and an extra `src` folder in Roblox.

## 0.1.0

- Enabled strict Luau type checking across the package.
- Added typed per-instance and global blur intensity controls.
- Replaced per-instance render connections with a cached shared renderer.
- Added lifecycle handling for UI animation, reparenting, insertion, and destruction.
- Added runtime Normal and Fragmented Part/SpecialMesh templates.
- Added Moonwave API documentation and usage guides.
